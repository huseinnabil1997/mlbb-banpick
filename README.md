# MLBB Ban & Pick

Draft helper for Mobile Legends. Pick and ban suggestions use official rank relation scores (Mythic and All Rank) from [mobilelegends.com/rank](https://www.mobilelegends.com/rank), snapshotted 2026-10-10.

Open `index.html` or https://huseinnabil1997.github.io/mlbb-banpick/

Hero nicknames for search and speech live in `js/hero-aliases.js`. Speech uses the browser Web Speech API, then fuzzy-matches the transcript to hero names.
